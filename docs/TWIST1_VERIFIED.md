# Twist #1 — federal funding pathway (verified draft)

**Possible future federal R&D source:** [NSF SBIR Phase I](https://www.nsf.gov/funding/opportunities/small-business-innovation-research-small-business-technology/nsf26-510/solicitation). An eligible U.S. small business may request up to **$305,000 for 6–18 months** of technical R&D, subject to available funds. It must first submit an [NSF Project Pitch](https://seedfund.nsf.gov/project-pitch/) and receive an official invitation. CHIRP has no company eligibility finding, invitation, award, or venue/agency partner. Integrating ggwave, a signature and a PWA alone does not establish the novelty NSF seeks.

**Technical research question:** can a short authenticated acoustic advisory pass through real noisy venue speakers to prepared phones with useful latency and a low error rate, while displaying exact approved wording offline? A paid venue design pilot would first establish a customer need and access to representative PA equipment.

**Build change and proof for this twist:** `scripts/funding-evidence.mjs` now exports `docs/twist1-evidence.json`. It verifies the current signed 100-character TEST code with a hypothetical gate scenario, rejects altered signatures, and measures ggwave **digital waveform loopback** at 6.83 s (FAST) and 3.75 s (FASTEST). The signed TEST meaning comes from phrasebook type 12; wire v1 has no separate TEST flag. The JSON explicitly reports `speaker_to_phone_trials`, `offline_phone_trials`, and `venue_reach` as `null`. `scripts/test-demo-policy.mjs` separately checks the narrow receiver policy. The CAP parser can preview samples but cannot broadcast them in this build. These are software checks, not evidence of a working acoustic venue deployment. Run both scripts and capture their terminal output for the response.

We will use those next experiments to decide whether an NSF pitch is justified.”
