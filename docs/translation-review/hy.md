**Status:** NOT reviewed yet (machine-drafted)

Thank you for checking! These short messages appear on phones during emergencies and stadium events. They have to be **correct, short and calm**: a scared person reads them in two seconds.

**Note:** this draft is **Eastern Armenian**. Many LA Armenians (Glendale, Burbank) read **Western Armenian**. Tell us which one you speak, and whether a Western version is needed. That would be one more phrasebook entry, again with no code change.

**How to review (about 5 minutes):**
1. Read each row. If the translation is fine, tick ☐ → ☑ (or just tell us "row 3 OK").
2. If it's wrong, awkward or too long, write a better version in **Fix**.
3. Watch especially for: the evacuate / shelter commands (rows 1–3), anything that sounds like a *promise* that help is coming (it must not), and words that sound alarming or rude.
